# Пропуски в сьюте

**Пропусков без условия (`@pytest.mark.skip`) в сьюте нет.** Три последних сняты
2026-09-03, и каждый скрывал дефект: «Windows file lock issue» — сломанный parquet,
«API changed» — потерянный замер производительности, «requires specific format» —
неверную фикстуру. Девять пропусков по удалённому `MACDZoneAnalyzer`, которые описывала
прежняя редакция этого файла (2025-10-28, «12 пропущенных из 682»), ушли вместе с модулем.

Что остаётся — **условные** пропуски, и каждый называет условие в коде:

- `@pytest.mark.skipif(...)` — недоступная опциональная библиотека (TA-Lib) или
  окружение, где проверка бессмысленна;
- `pytest.skip(reason)` внутри теста — состояние, в котором утверждать нечего, с
  причиной в сообщении (например, TA-Lib загружен, и ветка «библиотека отсутствует»
  недостижима).

В полном прогоне на 2026-09-04 пропущено 33 теста, и все 33 — одна параметризованная
проверка `tests/unit/test_scripts_parity.py` на блокирующий `plt.show()`: она
пропускает скрипты, которые matplotlib не используют, и говорит об этом («script does
not use pyplot»).

Числа прогонов — в `changelogs/CHANGE_TRACE_LOG_YYYY-MM-DD.md`, не здесь.
