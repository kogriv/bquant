# Командная строка (`bquant`)

После установки пакета в `PATH` появляется исполняемый файл `bquant`. Он даёт быстрый
доступ к анализу зон на встроенных наборах данных — без написания скрипта — и, что важнее,
умеет отдавать результат **структурно**, для программы, а не только для чтения глазами.

```bash
pip install bquant
bquant analyze
```

## Команды

| Команда | Что делает |
|---------|------------|
| `bquant analyze [набор]` | Считает зоны по выбранному индикатору и строит график |
| `bquant list` | Перечисляет встроенные наборы данных |
| `bquant status` | Показывает статус встроенных наборов |

## `bquant analyze`

```bash
# Зоны по MACD на наборе по умолчанию (tv_xauusd_1h)
bquant analyze

# Другой набор
bquant analyze mt_xauusd_m15

# Другой индикатор: зоны детектируются по нему
bquant analyze --indicator rsi
bquant analyze -i ao

# Структурный вывод для программы
bquant analyze --json

# Только расчёт, без отрисовки — заметно быстрее
bquant analyze --json --no-chart

# Куда сохранить график
bquant analyze --output chart.html
```

### Флаги

| Флаг | Значение |
|------|----------|
| `--indicator`, `-i` | `macd` (по умолчанию), `rsi`, `ao` |
| `--output`, `-o` | путь к HTML-файлу графика; без него — `results/charts/` |
| `--json` | структурный вывод вместо текстового отчёта |
| `--no-chart` | не строить график |
| `--quiet`, `-q` | минимальный вывод |

### Что печатает текстовый режим

```
Набор данных: tv_xauusd_1h
Индикатор:    macd
Найдено зон:  32
  по типам:   bear: 16, bull: 16
  длительность (баров): мин 1, средн 31.2, макс 98
Кластеров:    3
Колонки индикатора:
  macd_12_26_9:hist -> macd_12_26_9__hist
  macd_12_26_9:line -> macd_12_26_9__line
  macd_12_26_9:signal -> macd_12_26_9__signal
График: results/charts/zones_macd_tv_xauusd_1h_20260828_130000.html
```

Колонки печатаются **вместе с ролями** (`line`, `signal`, `hist`, `value`) не для красоты:
имя колонки говорит, какой экземпляр индикатора её посчитал, а роль — что ряд означает.
Подробнее — [Core Concepts](core_concepts.md).

### Структурный вывод (`--json`)

Тот же результат, из той же сводки, что и текст, — расхождение между ними невозможно
по построению. Ниже **сокращённый** вид: у `duration_filter`, `total_statistics` и
`columns` полей больше, полный набор смотрите прогоном `bquant analyze --json`.

```json
{
  "schema_version": 1,
  "dataset": "tv_xauusd_1h",
  "indicator": "macd",
  "zones": {
    "total": 32,
    "by_type": {"bull": 16, "bear": 16},
    "duration": {"min": 1, "max": 98, "mean": 31.25}
  },
  "duration_filter": {"min_duration": 1, "zones_analysed": 32, "zones_excluded": 0},
  "total_statistics": {"total_zones": 32, "bull_ratio": 0.5, "bear_ratio": 0.5},
  "columns": {"macd_12_26_9:line": "macd_12_26_9__line"},
  "clustering": {"n_clusters": 3}
}
```

У структуры есть `schema_version` — потребитель здесь программа, и без номера она не
отличит смену формы от смены данных.

**Считайте зоны по `zones.by_type`, а не по `total_statistics`.** Первое строится по
фактически встреченным типам и потому верно для любого индикатора; второе приходит из
библиотеки и содержит `bull_*`/`bear_*`, посчитанные по двум литеральным именам. Для RSI
или AO эти поля равны нулю при непустом наборе зон — ноль там означает «такого типа нет»,
а не «измерено ноль». Известное расхождение, разбор —
`devref/gaps/zone_types/g34_aggregate_statistics_speak_macd_2026-08.md`.

## Индикатор — параметр, а не значение слова «анализ»

Пайплайн зон индикатор-агностичен, и CLI это наследует. Разные индикаторы дают разные
**словари типов зон**, и это нормально:

| Индикатор | Детекция | Типы зон |
|-----------|----------|----------|
| `macd` | пересечение нуля линией MACD | `bull`, `bear` |
| `rsi` | пороги 30/70 | `oversold`, `neutral`, `overbought` |
| `ao` | пересечение нуля | `bull`, `bear` |

RSI и AO объявляют одну роль `value`, а не тройку MACD, — график для них строится
однопанельный, с теми же закрашенными зонами.

## Использование из кода

Команды — тонкая обёртка над функциями, которые можно звать напрямую. Они ничего не
печатают и **поднимают исключения**, а не завершают процесс:

```python
from bquant.cli import run_zone_analysis, summarize

result = run_zone_analysis('tv_xauusd_1h', indicator='macd')
print(len(result.zones))

summary = summarize(result, dataset_name='tv_xauusd_1h', indicator='macd')
print(summary['zones']['by_type'])
```

`run_zone_analysis` возвращает обычный `ZoneAnalysisResult` — тот же, что даёт
[универсальный пайплайн](zone_analysis.md), со всеми зонами, признаками и статистикой.
Для полного контроля над конфигурацией используйте билдер `analyze_zones()`, а не CLI.

## Ограничения

- Работает только со **встроенными** наборами (`bquant list`). Загрузка своих файлов —
  через `bquant.data.loader` в коде.
- Параметры индикаторов зафиксированы на значениях пресетов (MACD 12/26/9, RSI 14 с
  порогами 30/70, AO 5/34). Менять их — через `analyze_zones()`.
