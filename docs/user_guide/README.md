## Что нужно знать заранее

- **Python 3.12+** — это требование самого пакета (`requires-python`).
- pandas и numpy на уровне «читаю и фильтрую `DataFrame`».
- Что такое OHLCV.

Отдельно ставить `pandas`, `numpy`, `plotly`, `matplotlib` не нужно — они приходят
зависимостями вместе с `pip install bquant`.
