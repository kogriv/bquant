# Tutorials

Четыре пошаговых сценария. Каждый исполняется на встроенном сэмпле `tv_xauusd_1h`
(1000 часовых баров XAUUSD) и не требует внешних файлов; все числа в тексте получены
прогоном на текущей версии пакета.

| Tutorial | Что показывает | Начинать, если |
|---|---|---|
| [MACD zones](macd_basic_pipeline.md) | базовый конвейер `analyze_zones()`, чтение результата, три режима визуализации | вы ещё не запускали пайплайн |
| [RSI zones](rsi_strategy_switching.md) | смена стратегии детекции `threshold` → `line_crossing` без пересчёта индикатора | хотите сравнить два способа резать один и тот же ряд |
| [Combined rules](combined_rules_detection.md) | зоны по собственным условиям с логикой AND/OR, отладка правил вне пайплайна | стандартные стратегии не описывают вашу разметку |
| [Preloaded zones](preloaded_zones_workflow.md) | зоны из внешней разметки (CSV или `DataFrame`) и их сравнение с автоматической детекцией | зоны уже есть, нужен анализ |

Порядок — сверху вниз: каждый следующий опирается на предыдущий.

## Перед началом

- Python 3.12 или новее, `pip install bquant`. Визуализация работает на Plotly, он
  ставится зависимостью.
- Понимание OHLCV-данных. Как устроен сэмпл — в [описании встроенных данных](../api/data/samples.md).
- Если пайплайн для вас новый, сначала — [Быстрый старт](../user_guide/quick_start.md).

## Готовые скрипты

Tutorials — короткий путь. Длинный — исполняемые скрипты в репозитории:

- `examples/` — сценарии от базовых индикаторов до визуализации; разбор в
  [обзоре примеров](../examples/README.md).
- `research/notebooks/` — исследовательские скрипты в стиле ноутбука
  ([NotebookSimulator](../api/core/nb.md)); запускать с флагом `--no-trap`, иначе они
  ждут `Enter` между шагами.
