## 1. Почему релиз, а не «накопим ещё»

Обычный довод к релизу — «набралось улучшений». Здесь довод другой: **на PyPI сейчас
лежит версия, которая у части пользователей не работает вовсе**, и починка уже готова,
но живёт только в git. Три замера на чистом окружении с `pip install bquant==0.0.7`:

| Что | Что происходит на опубликованной 0.0.7 |
|-----|----------------------------------------|
| `import bquant` при `site-packages` без права записи | `PermissionError: '…/site-packages/logs'` — отказ импорта (G24) |
| `import bquant` при обычных правах | пакет заводит `site-packages/logs/` и пишет туда свой лог (G24) |
| `bquant analyze` | печатает `⚠️ Не удалось создать график`, файла не создаёт и возвращает **0** |

Третья строка — уже починена в `main` (`64fb798`): проглоченной причиной был
`Invalid frequency: 1H`, то есть строка синтеза оси времени не только выдумывала даты,
но и протухла — в актуальной pandas прописная `H` больше не частота.

## 2. Шаги

| # | Шаг | Статус |
|---|-----|--------|
| 1 | **Пины на установленную форму пакета.** Их нельзя написать «по рабочей копии»: там `PROJECT_ROOT` угадывает правильно, и дефект невидим. Утверждать: импорт ничего не создаёт; при корне, не похожем на чекаут, записываемые пути лежат вне пакета; чекаут опознаётся по признакам чекаута | ⬜ |
| 2 | **Убрать создание каталогов с импорта** (`config.py:23`). Все реальные писатели создают каталог сами (`core/utils.py:63`, `core/logging_config.py:191`, `core/cache.py:263`) | ⬜ |
| 3 | **Развести «корень исходников» и «куда писать».** `PROJECT_ROOT` остаётся как есть; записываемые по умолчанию пути берутся от отдельного корня: рабочая копия → корень репозитория (поведение разработчика не меняется), установленный пакет → `$BQUANT_HOME`, иначе `~/.local/share/bquant` | ⬜ |
| 4 | **Проверка установкой, а не по чекауту.** Собрать колесо, поставить в чистое окружение, прогнать при read-only `site-packages`. Это единственная проверка, которая вообще что-то доказывает про G24 | ⬜ |
| 5 | **CHANGELOG 0.0.8** — из трейслогов за 2026-08-28 | ⬜ |
| 6 | **Релиз:** версия в трёх местах (`pyproject.toml`, `bquant/__init__.py`, `uv.lock` через `uv lock`), отдельный коммит `release: bquant 0.0.8`, аннотированный тег, пуш через `origin` (уходит на оба зеркала — RTD собирается из GitLab), сборка и `twine upload`, проверка установкой из PyPI | ⬜ |

## 3. Что в 0.0.8 попадает из уже сделанного

- **CLI перестал выдавать не то, что обещает имя команды** (`64fb798`, `68618bd`):
  зоны считаются и показываются, ось времени берётся из данных, зоны размечаются там,
  где они есть, появились `--indicator`/`--json`/`--no-chart`, `sys.exit` ушёл из
  библиотечных функций. Разбор — `p2a_cli_backlog_2026-08.md`.
- **G24** — этот бэклог, шаги 1–4.
