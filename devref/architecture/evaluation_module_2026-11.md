# `bquant.analysis.evaluation` — оценка списка сделок (проект, 2026-11-03)

**Тип:** проектная записка перед кодом. **Запрос:** внешняя лаборатория стратегий (репозиторий
`mql`) — обобщённое из нескольких её исследований переезжает в пакет;
лаборатория затем переходит на пакет с проверкой «те же числа» у себя. Спецификация с
замороженными определениями и синтетическая фикстура — её; эталонный код читался, не копировался.
Числа и данные лаборатории в пакет не входят.

## 1. Что это и чего в пакете не было

Объект — **кадр сделок**: одна строка — одна сделка. Ничего в пакете этот объект не знало:
`ValidationSuite` работает над функцией анализа на ценовом кадре, `HypothesisTestSuite` — над
признаками зон. Новое — четыре части, все над кадром сделок:

| часть | вопрос | модуль |
|---|---|---|
| блочный бутстреп по календарным месяцам | интервал и стандартная ошибка среднего при перекрывающихся сделках | `bootstrap.py` |
| случайный базис входа | ожидание того же входа на случайном баре того же года; преимущество = исход − ожидание | `baseline.py` |
| сводка и критерий | `trial_stats`, Бенджамини–Хохберг с `m` от вызывающего, правила-объекты, `pass` | `criterion.py` |
| процедура по окнам | выбранный проход против умолчаний, среднего по сетке и оракула; `t` парной разности | `procedure.py` |
| квартальная мерка | доля кварталов в плюсе, медиана, худший, mean/σ, просадка, дольше всего без максимума | `quarters.py` |

Дом — `bquant/analysis/evaluation/`, рядом с `validation/`. Не корневой пакет: корневой обязан
объявить слой в контракте (`codemap.toml`, `exhaustive = true`; сторож слоёв), а зависит модуль
только от `core`. Хартии не противоречит: это методология состоятельности с честным «не прошло»,
не поиск альфы; работа по явному запросу лаборатории (§3 хартии).

## 2. Контракт входа

| столбец | тип | обязателен | смысл |
|---|---|---|---|
| `entry_time` | datetime | да | закрытие бара входа |
| `exit_time` | datetime, `>= entry_time` | да | закрытие бара выхода |
| `side` | int ∈ {+1, −1} | да | покупка / продажа |
| `net` | float | да | исход после издержек в единицах оценки (масштаб — вызывающего: ATR, % цены, деньги) |
| `gross` | float | нет | исход до издержек; `cost = gross − net` |
| `rand` | float | нет | ожидание случайного входа; без него преимущество не считается |
| `hold` | int | нет | удержание в барах; нужно для базиса |
| `mode` | любая метка | нет | способ выхода сделки; нужен, если базис построен с `modes` (добавлено 2026-11-03) |

Выводятся `year`, `month = year·12 + month − 1` (целый ключ) по `entry_time`; квартал — по
`exit_time` и только для квартальной мерки. Нарушение контракта — `ValueError` с именем
столбца и тем, что требуется; молчаливого приведения нет. `NaN` в `rand` допустим: такая сделка
входит в `n`, но не в преимущество.

## 3. Определения (замороженные, по спецификации лаборатории)

- **Бутстреп.** Блоки — все месяцы отрезка `[m_min, m_max]`, **включая пустые**; список месяцев
  подаёт вызывающий (`months_between(start, end)` — помощник). Повтор: `M` индексов с
  возвращением из одного вызова `default_rng(seed).integers(0, M, (B, M))`; среднее повтора —
  `Σ W·S / Σ W·C` по суммам и счётчикам месяцев; знаменатель 0 → повтор `NaN` и **отбрасывается**
  (не перетягивается). Интервал — `numpy.quantile` (линейный) по оставшимся повторам; СО —
  `std(ddof=1)`, при ≤ 1 повторе `NaN`.
- **Базис.** Для (год[, час], сторона, H): точное среднее исхода по **всем** барам `e` отрезка,
  у которых окно `e … e+H−1` внутри отрезка; функция исхода — вызывающего (издержки, масштаб —
  в ней). Пустая клетка — `NaN`.
- **Сводка.** `net_mean`, `net_lo/hi`, `excess_mean/lo/hi/se`, `p = norm.sf(excess_mean /
  excess_se)` (СО 0 или `NaN` → `p = NaN`), `p_boot` для сверки, `hit`, по годам `n/net/ex`,
  `years_n` (годы с `n ≥ min_year_trades`), `years_net_pos`; `n = 0` → `{"n": 0}`.
- **БХ.** `m = max(m_total, число не-NaN p)`; `NaN` не ранжируются; недостающие до `m` — `p = 1`;
  `q_(i) = min_{j≥i} p_(j)·m/j`, обрезка 1. Кандидаты с `n < MinTrades.n` получают `p = NaN`
  **до** поправки, в `m_total` входят.
- **Правила.** `MinTrades(n)`, `NetPositive(use_ci)`, `YearsStable(share, min_years)`,
  `BeatsRandom(alpha, margin)`, `MinEffect(threshold)`; строгие неравенства как записано,
  равенство — «не прошло»; `pass = AND`.
- **Окна.** Выбранный = `argmax back`, при равенстве — меньший номер прохода; `defaults` —
  ровно один проход с параметрами умолчаний, иначе `NaN`; `percentile` — доля строго меньших;
  `t` парной разности при `n > 2` и `std > 0`, иначе `NaN`.
- **Кварталы.** Квартал календарный по `exit_time`; `q_ret = end/start − 1`, `start` — конец
  предыдущего квартала (первый — депозит); `max_dd = min(balance/cummax − 1)` по сделкам;
  `longest_underwater_days` — максимальный промежуток в целых днях между соседними датами
  новых максимумов.

## 4. Где пакет отходит от эталона — названо заранее

1. **Имена ключей сводки** — по спецификации (`net_mean`, `excess_mean`, …), без суффикса единицы:
   единица — вызывающего. `mfe`/`mae` не в контракте — не в сводке.
2. **Квартал без сделок.** Эталон даёт `NaN` (resample без наблюдений). Пакет переносит баланс
   (`ffill`): доходность 0, квартал **считается** — плоский квартал не положительный. На
   фикстуре не проявляется (кварталы сплошные); лаборатории названо.
3. **Хвост под водой.** `longest_underwater_days` по эталону не видит отрезок после последнего
   максимума до конца ряда — тот, что важнее всего в живом прогоне. Поле оставлено как есть и
   добавлено `underwater_tail_days` — дни от последнего максимума до последней сделки.
4. **`top_k_share`** в эталоне не реализован: доля прибыли `k` лучших кварталов в итоге =
   `Σ top-k (end − start) / (final − initial)`; при итоге `≤ 0` — `NaN`.
5. **Фикстура** переписана в нейтральных именах столбцов параметров (`a`, `b`); числа — те же
   синтетические (сид 20261103).

## 5. Сторожа и приёмка

- `tests/fixtures/evaluation/` — `trades.csv`, `windows.csv`, `balance.csv`, `expected.json`
  (выходы эталонного кода на синтетике). Тест воспроизводит каждое число `expected.json` до
  `1e-9` относительных — это и есть «те же числа» в пакете; «те же числа» на реальных прогонах
  лаборатория проверяет у себя после релиза.
- Отдельные сторожа на каждую запись §3–§4, мутационно: пустые месяцы входят в блоки
  (убрать — интервал сужается), повтор с нулём отбрасывается, `m` от вызывающего делает `q`
  строже, равенство — «не прошло», базис — точное среднее по полному перебору на малом ряде,
  квартал без сделок — 0 и считается.
- Доки: `docs/api/analysis/evaluation.md` (справочник) + раздел в `docs/api/analysis/README.md`
  и в `docs/user_guide/`; все числа в прозе — из запуска.

## 6. Чего модуль не делает

Не хранит реестр опробованных вариантов (`m_total` — от вызывающего), не знает про зоны, ряды,
советников и отчёты тестеров (разбор XML/XLSX остаётся у вызывающего), не несёт данных и
чисел лаборатории.


## Дополнение 2026-11-03 — режим выхода в базисе

По слову владельца, контракт — от лаборатории. `random_entry_baseline(…, modes={метка: хвост})`:
хвост — сколько баров сверх `e + H − 1` нужно выходу; верхняя граница входа сдвигается на
хвост, метка входит в ключ клетки, функция исхода получает её четвёртым аргументом. Без
`modes` — прежний вызов и прежняя таблица. Отступление от контракта лаборатории, названное
ей: сделки без столбца `mode` при таблице с режимами не считаются первым режимом, а
получают отказ. Сторож — `tests/unit/test_the_random_baseline_tells_exits_apart.py`
(фикстура лаборатории до `1e-9`, четыре мутации).
