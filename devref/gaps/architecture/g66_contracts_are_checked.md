## 3. Почему это форма «проверка не видит проверяемого»

Ключ, который различается между процессами, делает дисковый кэш проверкой с нулевым
результатом — промах неотличим от «не считали». Модель, принимающая три противоречащих
числа, заставляет каждого потребителя верить одному из них. Метаданные, хранимые
отдельно от данных, проверялись — но на реестр, а не на модуль, который данные несёт.

## 4. Что сделано

* **AQ-044** — `_feed_canonical()`: кадры/`Series` через `hash_pandas_object` с именами
  колонок и типами, массивы байтами с формой и типом, словари по отсортированным ключам,
  примитивы по `repr`; SHA-256; `DiskCache.get_entry()` и `MemoryCache.put(...,
  expires_at=)` — запись переезжает со своим сроком. Оставленная дыра названа: чужой
  объект с адресом в `repr`.
* **AQ-045** — `ZoneInfo`: `start_idx <= end_idx`, `duration == end_idx − start_idx + 1`,
  `start_time <= end_time`, `len(data) ∈ {0, duration}` (пусто — «кадр не приложен», так
  живёт результат, загруженный без кадра); `SwingContext`: `indices` отсортированы и
  совпадают с `swing_points[i].index`.
* **AQ-046** — сообщение `visualize()` называет реальные пакеты; `notebooks`/`full` без
  дублей базы; `README` ставит `.[dev]`.
* **AQ-053** — реестр хранит только человеческое (имя, описание, источник, лицензия,
  модуль); измеримое (`MEASURED_FIELDS`) `get_dataset_info()` читает из `DATASET_INFO`
  модуля, период — в ISO, размер — файла модуля; оба `DATASET_INFO` пересобраны из
  собственных `DATA`; генератор отказывает, если период не определён.
* Визуализатор строит временную зону из границ, без кадра; фикстуры режут ровно зону.

## 5. Сторожа

`tests/unit/test_contracts_are_checked.py` — ключ одинаков в двух процессах
(подпроцессы); дисковая запись доживает свой срок; согласованная зона принимается,
пустой кадр — «не приложен», четыре противоречия отвергаются по имени; несортированный
контекст и расхождение `indices`/`swing_points` отвергаются; каждая подсказка
`bquant[...]`/`.[...]` в пакете, README и доках называет существующий extra; extras не
повторяют базу; поля результата — словари, как в аннотации; метаданные обоих сэмплов
равны тому, что несут `DATA`, реестр без своих копий, `validate_dataset` зелёный;
генератор отказывает без периода.

## 6. Вынос базы в extras — отклонено владельцем (2026-09-06)

Аудит предлагал ядро из `numpy`/`pandas`/`scipy` и extras `viz`/`stats`/`notebooks`. Решение
владельца: **не делать**. `pip install bquant` продолжает приносить всё, что нужно для
анализа и графиков; extras, которые есть, честные и базу не дублируют.
