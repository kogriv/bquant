# G91. `find_datasets` возвращал разный порядок в каждом процессе

**Дата:** 2026-11-03 · **Тип:** data · **Приоритет:** 🟢 Low · **Статус:** ✅ исправлено 2026-11-03

`find_datasets()` собирал ответ пересечением множеств и возвращал `list(set)`. Хэш строк в
Python рандомизирован на процесс, поэтому один и тот же вызов печатал
`['mt_xauusd_m15', 'tv_xauusd_1h']` в одном прогоне и `['tv_xauusd_1h', 'mt_xauusd_m15']` в
другом. Найдено прогоном всех примеров доки (G92): на одном плече pandas пример
`docs/api/data/samples.md` совпал, на другом — нет, и это выглядело зависимостью от pandas,
хотя pandas ни при чём. Теперь ответ отсортирован; сторож — тот же пример доки, который
блок-проверка сверяет в каждом прогоне сьюта.
