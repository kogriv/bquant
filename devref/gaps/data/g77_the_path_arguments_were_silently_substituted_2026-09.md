# G77. Два аргумента пути молча подменялись, третий отказывал вслух

**Дата:** 2026-09-12
**Тип:** correctness
**Приоритет:** 🟠 Medium — опечатка в имени провайдера возвращала путь к чужому файлу
**Статус:** ✅ исправлено
**Найдено:** таблицей рычагов пути данных (§7.3, третья область)

---

## 1. Замер

```
data_source=tradingview     -> OANDA_XAUUSD, 60.csv
data_source=metatrader      -> XAUUSDH1.csv
data_source=does_not_exist  -> XAUUSD_1h.csv          # молча generic
quote_provider=oanda        -> OANDA_XAUUSD, 60.csv
quote_provider=forexcom     -> FOREXCOM_XAUUSD, 60.csv
quote_provider=nonexistent  -> OANDA_XAUUSD, 60.csv   # молча OANDA
timeframe='7x'              -> ValueError: Unsupported timeframe: 7x. Supported: [...]
```

Три аргумента одной функции: один проверяется и отказывает со списком допустимых, два
подменяются без единого слова.

`load_ohlcv_data(path, timeframe='not_a_timeframe')` загружал файл и возвращал кадр:
отказ `validate_timeframe` ловился и писался в лог как `warning`.

## 2. Почему это дефект, а не мелочь

Ответ **выглядит результатом**. `get_data_path('XAUUSD','1h', quote_provider='forexcomm')`
(опечатка в одну букву) возвращает существующий, законный путь — к файлу OANDA. Дальше одно
из двух: файла нет, и пользователь ищет ошибку не там; или файл есть, и в анализ уезжают
котировки другого провайдера под именем запрошенного.

У `load_ohlcv_data` цена та же формой: `timeframe` объявлен в докстроке как участвующий в
валидации, отказ понижен до строки в логе, и вызывающий узнаёт о своей ошибке никогда.

## 3. Исправление

Оба аргумента проверяются по словарю и отказывают с перечнем допустимых — так же, как
`validate_timeframe` строкой выше. Проверка таймфрейма в загрузчике вынесена **за** `try`:
внутри она была бы переименована в `DataLoadingError`, а это не отказ загрузки — файл
исправен, неверен запрос.

## 4. Сторож

`tests/unit/test_data_levers_change_the_answer.py`:

* положительный контроль — известный провайдер даёт **другой** путь (иначе прошёл бы
  сторож, отказывающий на всём подряд);
* неизвестный источник и неизвестный провайдер — `ValueError`, и в сообщении есть слово
  `Supported`;
* загрузчик: с допустимым таймфреймом читает 300 строк, с недопустимым — `ValueError`.

**Мутация:** вернуть `.get(x, fallback)` в обоих местах и убрать проверку из загрузчика —
три проверки краснеют, после отката зелёные.
