# G57 — Контракты данных расходились между слоями и молчали на краях

**Заведён:** 2026-09-04, из аудита качества (AQ-014–020, AQ-024–026).
**Статус:** ✅ закрыт 2026-09-05 — десять находок, каждая воспроизведена и закрыта; один хелпер на отношения OHLC для трёх слоёв.

---

## 1. Что было — замер

Каждый пункт воспроизведён на коде до правки (`tv_xauusd_1h`, если не сказано иное):

| 017 | 6-колоночный MT CSV без заголовка | **19 строк**, колонки `['3336.94', '3344.77', …]`, индекс — строки | 20 строк, `open…volume`, `DatetimeIndex` |

Самые громкие: MT-файл, у которого первая строка данных стала заголовком, а цены —
именами колонок, и фильтр выбросов, удаливший постоянный ряд целиком (`0/0 = NaN`,
`NaN <= 3` — ложь для каждой строки).

## 2. Почему это форма «проверка не видит проверяемого»

Все десять — проверки или преобразования, которые на краевом входе выдавали
правдоподобный ответ вместо отказа: схема считала колонки данными, сниффер формата
проверял `isinstance(str(v), str)` (истинно для чего угодно) **после** чтения с
`index_col=0`, которое само отнимало колонку; частично распарсившееся время принималось
как ось; допуск «для мержа» расширял то, что должен был лишь находить; соседство зон
проверялось `<=`, принимающим и пересечение, и обратный порядок. Инвариант OHLC был
записан четыре раза с четырьмя строгостями.

## 3. Что сделано

- **`ohlc_violations(df)`** в `schemas.py` — три отношения, один раз; его читают схема
  (`add_frame_rule`, новые `frame_rules`/`min_rows` у `DataSchema`), `validate_ohlcv_data`
  и `_validate_ohlcv_structure` загрузчика (предупреждения по всем трём).
- Схема: `len(df) < min_rows` — отказ; обязательное поле, пустое целиком, — отказ.
- `validate_data_completeness`: на пустом кадре — вердикт до цикла долей.
- Загрузчик: сниффинг MT-формата по сырому семплу **до** любого `index_col`; признак —
  первая колонка разбирается как время в каждой строке (заголовок `time` не разбирается),
  колонки 1–5 числовые.
- `resolve_time_index`: колонка, разобравшаяся частично, — `ValueError` с числом и
  примерами; не разобравшаяся вовсе — по-прежнему «не время», позиции остаются (G30).
- Preloaded: строки в `start_time`/`end_time` разбираются (числа — позиции, их
  отклоняет `_require_comparable_clock` по имени); ось данных обязана быть уникальной и
  монотонной; зоны сортируются, пересечение / `end < start` / повтор `zone_id` — отказ
  (политика: отказ; слияние и событийный режим не реализованы — анализ
  последовательностей читает соседей как переход). Граница снапится к ближайшему бару в
  пределах допуска (`get_indexer(method='nearest', tolerance=…)`), позиции — из него;
  объявленные границы — в `indicator_context['declared_start_time'/'declared_end_time']`.
- Соседство: `start == prev_end + 1`; `start <= prev_end` — `ValueError` по имени.
- Выбросы: одна маска по исходному кадру, `std == 0` — нет выбросов, `NaN` — не выброс.
- Сессии: `london_ny_overlap` инициализируется `False`, dtype `bool`.
- `calculate_true_range()` — каноническое определение; `calculate_derived_indicators`
  пишет `intrabar_range` (`high - low`) и `true_range` (настоящий); `add_technical_features`
  зовёт ту же функцию.

## 4. Проверка

`tests/unit/test_data_contracts_agree_between_layers.py` — 22 проверки по всем десяти
пунктам. Существующий e2e-тест «позиции вместо времени отклоняются по имени» упал на
первой версии разбора дат (`pd.to_datetime(10)` — 1970 год) и заставил не трогать
числовые колонки.

| Мутация | Краснеет |
|---|---|
| схема: `min_rows` не проверяется | 1 |
| `ohlc_violations` возвращает `{}` | 2 (три слоя, схема) |
| сниффер MT после `index_col` (старый порядок) | 2 (шесть колонок; семь — тоже, порядок общий) |
| `resolve_time_index` принимает частичный разбор | 1 |
| допуск снова расширяет окно | 1 |
| соседство `<=` | 1 |
| выбросы по старому циклу | 2 |
| `true_range` = `high - low` в derived | 1 |

## 5. Цена

- `calculate_derived_indicators` добавляет одиннадцать колонок, не десять: `true_range`
  изменил значение на гэпах, `intrabar_range` — новое имя для прежнего числа.
- `remove_price_outliers` больше не удаляет строки с `NaN` в проверяемых колонках.
- Preloaded-зоны с пересечениями, дубликатами id или на неуникальной оси — отказ;
  `time_tolerance` не расширяет зону.
- `resolve_time_index` на колонке времени с дырами — отказ (раньше — `NaT` в индексе).
- Пайплайн на последовательности с пересечениями — отказ.

## 6. Чего не сделано

- Единый `DataValidationResult` для всех пяти функций валидатора (AQ-016, вторая часть):
  они по-прежнему отдают словари разной формы; переписывать форму пяти отчётов ради одного
  пустого кадра не стал — ключи задокументированы.
- ATR в `calculate_derived_indicators` (AQ-012, вне G57): ветка пайплайна, ждущая
  колонку `atr`, по-прежнему недостижима. Канонический True Range теперь есть — ATR
  строится из него в один шаг, когда будет решён его период и место в ключе кэша.
- Событийный режим preloaded-зон (пересекающиеся события) — не реализован, отказ назван.
