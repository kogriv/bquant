# G26 — Тест последовательностей фабриковал словарь типов зон и отвечал противоположное

**Заведён:** 2026-08-28 · **Статус:** ✅ **закрыт 2026-09-07** — правка в коде плюс страница
доки. Две первые редакции этой записи закрывали её как «дефект только в доке»; замер
2026-09-07 показал, что в доке был **не весь** дефект.
**Как найден:** первая редакция — при разборе `KeyError: 'p_value'` в примере из
`quick_start.md` (G25 §2, п. 8). Настоящая причина — при проходе по остаткам реестра
2026-09-07, замером самостоятельного пути на встроенном сэмпле.

---

## 1. Две предыдущие редакции и что в них было верно

Первая редакция диагностировала «словарь типов зон **теряется** на границе со списком
словарей, нужен новый параметр». Это опровергнуто: параметр `vocabulary=` есть у обоих
входов (`run_all_tests`, `run_all_hypothesis_tests`) и описан в
`docs/api/analysis/statistical.md`.

Вторая редакция закрыла запись как дефект доки: две страницы показывали вызов без
`vocabulary`, третья — правильный. Страницы починены в рамках G25, и это тоже верно.

Что обе редакции пропустили: **они мерили только сводку** — «5 из 7 тестов дают
`p_value`». Пятёрка выглядела как «работает», а внутри неё был тест, который ответил не
то, что называл.

## 2. Замер 2026-09-07 (`tv_xauusd_1h`, MACD, 77 зон)

Один и тот же вызов `run_all_hypothesis_tests(zones_features, alpha=0.05)`:

| тест | без `vocabulary` | с `vocabulary` |
|---|---|---|
| `contrast_asymmetry` | отказ, причина названа | p = 0.0441 |
| `correlation_drawdown` | отказ, причина названа | p = 0.0044 |
| **`sequence_patterns`** | **p = 1.0, «не значим»** | **p = 0.0, значим** |
| остальные четыре | без изменений | без изменений |

Сводка при этом сообщала `tests_executed: 5, tests_failed: 2` — то есть считала
`sequence_patterns` **выполненным**.

## 3. Механизм

```python
if vocabulary is None:
    vocabulary = ZoneVocabulary.coerce(sorted(set(zone_types)))   # ← фабрикация
```

`coerce` по именам строит словарь **без свойств** (это by-design: словарь свойств закрыт,
см. G20). Дальше тест бинаризует ряд по полярности:

```python
directional = [... for zone_type in zone_types
               if vocabulary.polarity_of(zone_type) in (-1, 1)]
```

У сфабрикованного словаря полярности нет ни у одного типа → `directional` пуст → runs-тест
пропускается → `combined_p = min(chi2_p, 1.0)`, и результат уезжает наружу с
`test_type="Chi-square and runs tests"`.

Почему это не «более слабый ответ», а **противоположный**: зоны MACD строго чередуются,
то есть последовательность максимально неслучайна. Весь сигнал — в runs-половине
(`runs_p = 1.15e-09` на синтетическом ряду из 40 зон), а chi2 по переходам на
чередующемся ряду почти равномерен (`chi2_p = 0.873`; на сэмпле — ровно 1.0). Выбрасывая
runs, тест отвечает «последовательность случайна» на самой неслучайной из возможных.

Два соседних направленных теста в такой ситуации **отказываются считать**. Этот —
единственный из трёх, у которого половина не направленная, и потому он единственный, у
кого была возможность ответить наполовину, не сказав об этом.

## 4. Правка

`bquant/analysis/statistical/hypothesis_testing.py`:

1. **`vocabulary is None` → отказ**, а не фабрикация. Сообщение называет, чего не хватает
   и как это получить (`resolve_vocabulary(zones)`), как у двух соседей.
2. **Словарь объявлен, но направления в нём нет** — законный случай, он остаётся: chi2
   считается, runs пропускается. Но теперь об этом говорит **вердикт**, а не только
   metadata: `test_type = "Chi-square only (runs test skipped: no directional zone types)"`.
   Chi2-половина больше не носит имя полного теста.

Пайплайн не затронут: `UniversalZoneAnalyzer` резолвит словарь из зон и передаёт его —
7 из 7 тестов как раньше. Меняется только прямой вызов по словарям признаков: 5 «выполненных»
из 7 превратились в 4 выполненных и 3 названных отказа.

## 5. Сторож

`tests/unit/test_the_sequence_test_needs_a_declared_vocabulary.py` — четыре проверки:
отказ без словаря (и что сообщение называет `resolve_vocabulary`); **противоположность
вердиктов** на одних данных под словарём с полярностью и без; вердикт называет, какой тест
посчитан; сводка кладёт отказ в `failed_tests`, а не в выполненные.

Мутации: вернуть фабрикацию словаря — 2 красных; вернуть `test_type` полного теста
chi2-половине — 1 красный.

## 6. Урок

Прежний урок записи («прежде чем объявлять „возможности нет“, проверить сигнатуру»)
остаётся верным. К нему добавился второй, стоивший этой записи девяти дней открытого
статуса: **счётчик выполненных тестов — не замер**. «5 из 7» читалось как «пять
работают», а внутри пятёрки был тест, отвечавший на другой вопрос под своим именем.
Мерить надо не число ответов, а сами ответы: тот же вход, две конфигурации, сравнить
вердикты.
