# G63 — Тесты нормальности с разной семантикой под одним вердиктом

**Заведён:** 2026-09-05, из аудита качества (AQ-030).
**Статус:** ✅ закрыт 2026-09-05 — Лиллиефорс вместо KS с оценёнными параметрами, порог Андерсона по `alpha`, консервативная политика `test_normality()`, `count` без NaN.

---

## 1. Что было — замер

| Вход | Ответ было | Ответ стало |
|---|---|---|
| нормальная выборка, `alpha = 0.01` → Anderson-Darling | критическое значение **0.75 (5 %)** при доступном 1.032 (1 %) | 1.032 |
| равномерная выборка (300, `[-1.7, 1.7]`), `alpha = 0.05` | Shapiro **отверг**, KS **принял**, Anderson отверг → `test_normality()` = **True** | Lilliefors отверг → `False` |
| `descriptive_statistics([1, 2, NaN, 4])['count']` | **4** при остальных статистиках по трём значениям | 3 |

KS с `args=(mean, std)`, оценёнными по той же выборке, использует p-value полностью заданной
нормали и слишком снисходителен — ровно тот случай, для которого существует поправка
Лиллиефорса. `critical_idx = 2` — всегда 5 %. «Нормально, если принял хоть один из трёх» —
политика, при которой достаточно одного снисходительного теста.

## 2. Что сделано

- `results['lilliefors']` вместо `results['kolmogorov_smirnov']`; без алиаса. Реализация своя —
  `lilliefors_normal()`: KS-расстояние до нормали с параметрами выборки, p-value методом
  Монте-Карло (2000 выборок того же размера, сид 0). `statsmodels.stats.diagnostic.lilliefors`
  на связке чистого клона (scipy 1.18.1 + statsmodels 0.15.0) падает `TypeError: ndtr()`;
  локальные версии (1.17.0 + 0.14.6) этого не показывали — гейт из чистого клона показал.
  Тот же `TypeError` даёт на scipy 1.18.1 и сам `scipy.stats.kstest(x, 'norm', args=(mean, std))`
  — то есть прежний KS на чистой установке 0.0.12 **молча выпадал** под
  `except Exception: logger.warning`, и в результате просто не было ключа. Теперь тест, который
  не выполнился, записывается в результат как `{'error': …}`; статистика Лиллиефорса считается
  без `kstest(args=)` — прямой формулой.
- Anderson-Darling: критическое значение для переданного `alpha` из `significance_level`
  (0.15, 0.10, 0.05, 0.025, 0.01); иное — `ValueError` с перечнем, а не молчаливые 5 %.
  В результате — `alpha`.
- `test_normality()`: `True`, только если каждый выполнившийся тест принял; ни одного
  выполнившегося — `False`.
- `count` — `data.count()`, как остальные статистики.

## 3. Проверка

Та же папка тестов: равномерная выборка отвергнута всеми тремя и хелпером; нормальная —
принята; порог Андерсона совпадает со `scipy` для 0.01/0.05/0.10 и отказ на 0.03; `count`.
Мутации: KS вместо Лиллиефорса — 1; Андерсон по 5 % — 1; `count = len` — 1.

## 4. Цена

Ключ `kolmogorov_smirnov` → `lilliefors`; `normality_test(alpha=0.03)` — отказ;
`test_normality()` строже; `count` меньше на число NaN.
